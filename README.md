# Sps-l Stepss

## How do I install these formulae?

`brew install sps-l/stepss/<formula>`

Or `brew tap sps-l/stepss` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "sps-l/stepss"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
